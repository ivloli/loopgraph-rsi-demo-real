# LoopGraph RSI Real Demo

This repository is the real GitHub target for the bounded RSI demonstration.

The v1 baseline intentionally contains a synthetic fallback in the supervisor policy. Future AI proposals must be based on the current canonical commit, pass the repository tests, and proceed through one coordinated pull request with human review.

## Release Flow

```text
canonical baseline -> AI candidates -> Host coordination -> one PR -> human review -> merge/tag
```

No credential or runtime state belongs in this repository.
